# OpenCNPJ

API Open Source de recuperação e busca de Cadastros de Nacionais de Pessoas Jurídicas (CNPJ).

[![.NET](https://img.shields.io/badge/.NET-%209-purple)](https://dotnet.microsoft.com/)
[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

## Visão geral

O OpenCNPJ é uma implementação completa e modular criada em .NET que tem como o propósito facilitar a busca por CNPJs.

Os dados recuperados são salvos utilizando o MongoDB e afim de manter a aplicação operacional é utilizado o SQLite para informações referentes a aplicação.

## 🚀 Início Rápido

### 1. Instalação básica

```Bash
git clone https://github.com/pedrozandonai/OpenCNPJ.git

cd OpenCNPJ/src/OpenCnpj.WebApi

dotnet run Program.cs

```

### 2. Dockerfile

```Bash
git clone https://github.com/pedrozandonai/OpenCNPJ.git

cd OpenCNPJ/src

docker run

```

### 3. docker-compose

```Bash
git clone https://github.com/pedrozandonai/OpenCNPJ.git

cd OpenCNPJ/src

docker run

```
